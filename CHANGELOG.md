# Changelog

## 0.1.0 — Initial release preparation

- Rust desktop interface for IPv4 range and port selection, discovery, filtering,
  searching and exporting results.
- Source project moved to the repository root; local build products and scan
  configuration separated from source control.
- Writable per-user configuration directory and a custom data-directory override.
- Windows x86/x64 installer and portable ZIP packaging with SHA-256 checksums.
- Windows CI and tag-triggered draft release automation.
